# Novelty and evidence-landscape plan

## Honest positioning

MOSAIC-Tx is a new project design, but this repository does **not** claim that every component is
unprecedented. Signature reversal, perturbational transcriptomics, cell-cell communication,
single-cell transplant atlases, causal graphs, and safety-aware ranking each have prior art. The
testable contribution is their patient-conditioned integration and validation under explicit
transplant constraints.

## Phase 0 review protocol

Before a grant, paper, or public novelty claim:

1. Register databases, queries, dates, inclusion criteria, and reviewer workflow.
2. Search PubMed, Europe PMC, ClinicalTrials.gov, bioRxiv/medRxiv, NIH RePORTER, Lens/Google Patents,
   and relevant conference proceedings.
3. Build a feature matrix covering patient conditioning, cell-state resolution, spatial context,
   perturbation source, causal method, safety constraints, uncertainty, external validation, wet-lab
   validation, and prospective testing.
4. Have two reviewers independently screen and extract; resolve disagreements and archive a PRISMA
   flow diagram.
5. Rewrite the contribution statement against the nearest systems and obtain technology-transfer
   review before disclosure if patentability matters.
